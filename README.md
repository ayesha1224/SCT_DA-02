Data Cleaning – Global Superstore Dataset
This project focuses on basic data cleaning and preparation using Python. The dataset used is the Global Superstore dataset, which contains sales records from different regions, categories, and customers.
The goal of this project is to prepare raw data so it can be used for further analysis. Real-world datasets often contain issues like missing values, duplicate records, or inconsistent formats. In this project, these problems were identified and handled using the Pandas library.

What was done in this project
- Loaded the dataset using Python
- Explored the dataset to understand its structure
- Checked for missing values in different columns
- Removed duplicate rows from the dataset
- Converted date columns into proper datetime format
- Saved the cleaned dataset as a new CSV file

Tools Used
- Python
- Pandas
- Visual Studio Code

Project Files
- "Global_Superstore2.csv" – Original dataset
- "data_cleaning.py" – Python script used for data cleaning
- "cleaned_superstore.csv" – Final cleaned dataset ready for analysis

Result
After cleaning the data the data set become more consistent and easier to work with.The cleaner data set can be now be used for further data analysis,visualization or machine learning tasks.
